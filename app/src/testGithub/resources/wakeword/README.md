Test audio for the wake word tests.

- `hey_buddy*.wav`: examples from the hey-buddy dataset (huggingface.co/datasets/benjamin-paine/hey-buddy), CC BY 4.0.
- `librispeech-3min.ulaw`: the first 3 minutes of the 73 utterances in `hf-internal-testing/librispeech_asr_dummy`
  (LibriSpeech, Panayotov et al., openslr.org/12, CC BY 4.0), joined, 16 kHz mono, 8-bit G.711 mu-law, no header.
